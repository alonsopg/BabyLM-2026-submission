\appendix

\section{Implementation Details}

The code is organized in \texttt{../babylm-hhm}. Core masking classes are in \texttt{src/masking/}. Configurations cover the random baseline, HHM, entity-only, error-only, randomized sketch control, frequency-only control, CMS-Morph, Accuracy-Morph, and Entity-Accuracy-Morph. The official BabyLM evaluation repository is available locally and was used for the reported strict zero-shot diagnostics.

\section{Compute Environment}

All full training runs were executed with CUDA visible on a single NVIDIA RTX A6000 GPU with 49{,}140 MiB of GPU memory. The NVIDIA driver reported by \texttt{nvidia-smi} was 535.288.01. The experiment environment was \texttt{ir-model-compression}, with Python 3.10.20, PyTorch 2.5.1+cu121, CUDA 12.1, Transformers 5.7.0, and Datasets 4.8.5. The training scripts used one GPU; no multi-GPU or distributed training was used.

\section{Training Configuration}

All main runs use the BabyLM 2026 Strict-Small dataset from \texttt{BabyLM-community/} \texttt{BabyLM-2026-Strict-Small}. The tokenizer is \texttt{bert-base-uncased}. The model is a compact BERT-style masked language model with hidden size 256, 4 hidden layers, 4 attention heads, intermediate size 1024, and maximum position embeddings 512. Training uses maximum sequence length 128, batch size 64, 10{,}000 training steps, learning rate $5 \times 10^{-4}$, weight decay 0.01, gradient clipping at 1.0, and a warmup fraction of 0.06. Validation uses 2{,}000 held-out examples and 40 evaluation batches at each evaluation point.

All systems preserve a 15\% total MLM mask rate. The random baseline masks valid positions uniformly. HHM uses the same mask rate with intended random, repeated-token, and raw-loss shares. CMS-Morph uses random, token-sketch, and character-trigram sketch shares. Accuracy-Morph uses an 80/15/5 random/token-correctness/trigram-correctness mixture after a 30\% adaptive warmup. The Accuracy-Morph sketches use Count-Min Sketch width 65{,}536, depth 4, conservative updates, character trigrams with boundaries, minimum seen count 3.0, smoothing alpha 1.0, and score cap 0.9.

\section{Run Commands}

Tests are run with \texttt{python tests/run\_tests.py}. The three-seed main comparison uses \texttt{scripts/run\_experiments.py} with the \texttt{main} suite and seeds 1, 2, and 3. The final Accuracy-Morph seed-2 run used CUDA device 0, the \texttt{src.training.train} entry point, \texttt{configs/accuracy\_morph\_seed2.yaml}, and seed 2.

The paper tables were populated from the lightweight CSV exports in \texttt{paper\_exports/} and from the official evaluation reports under the local BabyLM strict evaluation directory.
